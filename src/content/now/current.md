## Building

The festival platform for Same Same But Different is still active. It's a backend-first system that handled ticketing, scheduling, maps, and push notifications for around 7,500 attendees, with a hard ship date of August 24. That deadline is behind us now, and the work has shifted into the post-festival stretch: readiness cleanup, stability, and whatever surfaced from the live run.

herald-ui is an open-source Angular port of assistant-ui, a set of composable AI chat UI primitives. The goal is parity with the React ecosystem for teams building Angular frontends on top of LLMs. Currently in a personal agent test bed milestone, using it to validate the primitives in a real context before the broader push.

The portfolio site is in flight, working through an eval layer milestone. The core question I keep returning to: whether per-claim sidecar scores actually catch the synthesis failures I notice by eye when the wiki recompiles, or whether they're a false signal.
