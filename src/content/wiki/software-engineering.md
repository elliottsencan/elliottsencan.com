Software engineering is not reducible to writing code. The sources collected here span compiler internals, CI infrastructure, shell scripting, CSS platform capabilities, version control workflows, testing strategy, and the organizational and cognitive conditions under which code is actually produced and maintained. A unifying thread runs through most of them: the gap between the local act of producing code and the systemic challenge of owning it over time.

On design principles, several sources address how to structure code so it remains comprehensible. [AI Likes Deep Modules](/reading/2026-05/2026-05-04t231343-ai-likes-deep-modules) argues that hiding large implementations behind small interfaces reduces complexity for both human readers and LLMs. [Single Responsibility, the Distorted Principle](/reading/2026-06/2026-06-04t073318-single-responsibility-the-distorted-principle) corrects a common misreading: SRP is about cohesive grouping under a single accountable owner, not atomizing classes into single functions. [A Better Way to Build Angular Components](/reading/2026-04/2026-04-30t232001-a-better-way-to-build-angular-components-from-inputs-to) applies the same logic to component design, arguing that input-heavy monoliths should be refactored into composites with encapsulated concerns.

Testing occupies a substantial portion of the sources. [Designing Playwright Tests That Survive UI Refactors](/reading/2026-05/2026-05-05t135218-designing-playwright-tests-that-survive-ui-refactors) identifies the root cause of brittle test suites as coupling to implementation details rather than semantic roles. [Playwright Testing in Staging vs Production](/reading/2026-05/2026-05-15t120337-playwright-testing-in-staging-vs-production) frames environment choice as a decision with distinct operational costs. [Code Smells when you get AI to write your Frontend Tests](/reading/2026-06/2026-06-22t185420-code-smells-when-you-get-ai-to-write-your-frontend-tests) documents how AI-generated tests systematically over-mock, skip failure cases, and confirm bugs rather than intended behavior. [What CI Actually Looks Like at a 100-Person Team](/reading/2026-04/2026-04-30t195531-what-ci-actually-looks-like-at-a-100-person-team) shows what happens when CI reaches massive scale: 575K weekly jobs and 33 million test executions at PostHog, managed by an agent that traces flaky tests to root causes and opens fix PRs automatically.

Version control surfaces in two complementary pieces. [Reviewing Large Changes with Jujutsu](/reading/2026-05/2026-05-31t164252-reviewing-large-changes-with-jujutsu) describes a concrete workflow for reviewing large PRs without losing cognitive state, using jj's conflict-as-first-class-object model. [The Git Commands I Run Before Reading Any Code](/reading/2026-06/2026-06-18t024208-the-git-commands-i-run-before-reading-any-code) frames git log as a diagnostic instrument for churn hotspots, bus factor, and bug cluster analysis before a single file is opened.

Tooling and infrastructure appear across several entries. [Shell Tricks That Actually Make Life Easier](/reading/2026-04/2026-04-30t231815-shell-tricks-that-actually-make-life-easier-and-save-your) covers underused Readline bindings and script safety flags. [Using SSH Keys to Make Connectivity Simpler and Secure](/reading/2026-05/2026-05-04t231548-using-ssh-keys-to-make-connectivity-simpler-and-secure) walks through key generation and agent forwarding. [How Container Filesystem Works](/reading/2026-05/2026-05-04t231858-how-container-filesystem-works-building-a-docker-like) teaches container isolation from the Linux primitives up. [YAML? That's Norway Problem](/reading/2026-05/2026-05-18t113714-yaml-thats-norway-problem) traces a long-unfixed spec bug through library implementations, a reminder that widely-used formats carry subtle footguns.

The human and organizational dimensions are just as prominent. [The Bottleneck Was Never the Code](/reading/2026-05/2026-05-06t110728-the-bottleneck-was-never-the-code) argues that coding agents accelerate code production but amplify pre-existing organizational misalignment around specs and shared context. [Your Onboarding Is a Hazing Ritual](/reading/2026-05/2026-05-08t112608-your-onboarding-is-a-hazing-ritual-and-you-call-it-agile) documents how process theater systematically fails new hires while rendering the failure invisible to management. [Why Senior Developers Fail to Communicate Their Expertise](/reading/2026-05/2026-05-13t060018-why-senior-developers-fail-to-communicate-their-expertise) identifies a translation gap: engineers describe complexity management while stakeholders reason about uncertainty reduction. [The Tacit Dimension](/reading/2026-05/2026-05-19t110710-the-tacit-dimension-why-your-best-engineers-cant-tell-you) draws on Polanyi to argue that the most valuable engineering knowledge is structurally non-transferable to AI tools and can only move through apprenticeship.

Quality and correctness appear in several forms. [Approaching Zero Bugs](/reading/2026-05/2026-05-02t094735-approaching-zero-bugs) uses curl's vulnerability history to show no measurable evidence yet that AI-assisted static analysis is closing in on zero latent bugs. [When Code Is Cheap, Does Quality Still Matter](/reading/2026-05/2026-05-22t091746-when-code-is-cheap-does-quality-still-matter) answers yes: LLMs lower the cost of producing code, not the cost of owning it. [The Unwritten Laws of Software Engineering](/reading/2026-06/2026-06-10t073045-the-unwritten-laws-of-software-engineering) distills production-incident lessons into heuristics like rolling back before debugging. [Formal Methods and the Future of Programming](/reading/2026-06/2026-06-15t021106-formal-methods-and-the-future-of-programming) argues that agentic coding has made formal verification newly cost-effective precisely because the cost of generating proofs is falling while the need for guarantees beyond tests is growing.

On the AI-engineering interface specifically, the sources divide rather than converge. [Agentic Coding is a Trap](/reading/2026-04/2026-04-27t145041-agentic-coding-is-a-trap) warns that full delegation accelerates skill atrophy and vendor lock-in. [Slow Mode](/reading/2026-05/2026-05-19t193626-slow-mode) proposes a human-in-the-loop agent design that trades short-term throughput for genuine learning. [The Perils of AI to the Software Engineering Profession](/reading/2026-05/2026-05-14t223612-the-perils-of-ai-to-the-software-engineering-profession) draws a hard line at safety-critical systems. [The Coming Loop](/reading/2026-06/2026-06-23t161552-the-coming-loop) warns that harness loops amplify LLMs' worst tendencies, producing opaque, defensive code that requires machine participation to maintain. [Use Your Brain: Engineering Standards in the Age of LLMs](/reading/2026-08/2026-08-05t072544-use-your-brain-engineering-standards-in-the-age-of-llms) argues the corrective is stronger CI/CD, code ownership, and discipline rather than abandoning AI tools. [Learn Algorithms for Interviews, Forget Them for Work](/reading/2026-04/2026-04-30t155134-learn-algorithms-for-interviews-forget-them-for-work) sits somewhat apart, targeting the interview process itself as a poor proxy for production engineering ability: real work requires reading tradeoffs, shipping incrementally, and handling unbounded real-world inputs.
